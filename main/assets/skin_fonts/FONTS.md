# Skin fonts

Bitmap fonts for the three UI styles, generated by `scripts/fonts/build_fonts.py` from
the google/fonts repository. All source fonts are under the SIL Open Font License 1.1
(https://openfontlicense.org):

| Font | Copyright | Used by |
|---|---|---|
| Inter Tight | The Inter Project Authors | Instrument |
| IBM Plex Mono | IBM Corp. | Instrument |
| Inter | The Inter Project Authors | Orbit; fallback glyphs for Jost |
| Cormorant Garamond | Christian Thalmann | Atelier |
| Jost | Owen Earl (indestructible type*) | Atelier |

Regenerate with `python3 scripts/fonts/build_fonts.py` (needs fonttools and npx).
